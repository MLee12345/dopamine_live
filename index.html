About DopamineLive

A simulated ticket, wallet, and merch marketplace for high-demand live events.

Demo only. No real money is spent.
TL;DR

DopamineLive is a local simulation. It stores demo account names, virtual tickets, virtual merch, wallet balance, and profile history on this device so the experience can persist between reloads.

Fake tickets
Fake wallet
Local data
Purchases, discounts, queues, wallet charges, and checkout timers are all simulated. No external checkout occurs.

Privacy Details

DopamineLive keeps this prototype self-contained. The app uses your browser's local storage to remember the current account, guest session, saved virtual passes, merch cart state, profile history, wallet balance, and daily wheel status.

Account and Guest Separation

Guest mode and member mode use separate storage areas. A guest wallet, pass list, merch history, and deal state are not shared with a signed-in member account, and each username gets its own saved demo data.

What Is Stored

The app may store your demo username, demo password, editable display city, simulated ticket wallet, concerts attended, merch collected, saved cart data, virtual wallet amount, and active daily deal. This information stays on this device.

What Is Not Happening

No payment processor is contacted, no real tickets are issued, no venue inventory is reserved, and no real money is transferred. Checkout screens, scarcity warnings, queue progress, rewards, and taxes are interface simulations.

Reset and Logout

Logout returns you to the starting screen while keeping that account's local demo data. Reset Account deletes the current guest or member account's saved demo tickets, merch history, cart, wallet, and daily deal while keeping the account session open.

Control

You can change your profile name and city from the profile area when signed in. You can also reset the active session's data from the footer. Browser storage controls can clear all local prototype data from the device.
